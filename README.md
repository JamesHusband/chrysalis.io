# Chrysalis

<img src=".github/chrysalis.webp" alt="project-ideation platform" width="100%" />


**A project-ideation platform that carries an idea from loose inspiration all the way to a
development-ready design system.**

Each project begins as a moodboard: with collections of screenshots / UI references, layouts, colours all organised, tagged and foldered.

Curation alone isn't the point, though. Built into every project is a DESIGN.md editor that distils that visual intent into a precise, validated design system, covering colours, typography, spacing, component rules and a Tailwind config, with linting to keep it structurally sound and genuinely buildable.

## Prerequisites

- Node 22 (enforced via `.nvmrc`)
- [pnpm](https://pnpm.io/)

## Getting started

```bash
pnpm install
```
